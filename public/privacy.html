Kebijakan Privasi (Privacy Policy)

Aplikasi: MyKuliahLife - Student Financial & Academic OS • Terakhir Diperbarui: 29 September 2026 • Status: Berlaku & Terverifikasi
🔒 Komitmen Utama Perlindungan Data
Privasi Anda adalah prioritas mutlak kami. MyKuliahLife dirancang untuk membantu mahasiswa mengelola perkuliahan dan keuangan pribadi secara aman. Kami tidak pernah menjual, menyewakan, atau menyalahgunakan data pribadi Anda kepada pihak ketiga maupun pengiklan.

1. Pendahuluan

Kebijakan Privasi ini menjelaskan bagaimana MyKuliahLife ("kami", "aplikasi", atau "layanan kami") mengumpulkan, menggunakan, menyimpan, dan melindungi informasi pribadi pengguna saat menggunakan situs web dan aplikasi Progressive Web App (PWA) kami.

Dengan mengakses atau menggunakan MyKuliahLife, Anda menyatakan bahwa Anda telah membaca, memahami, dan menyetujui seluruh ketentuan dalam Kebijakan Privasi ini serta mematuhi peraturan perundang-undangan yang berlaku di Republik Indonesia, termasuk Undang-Undang No. 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP).

2. Informasi yang Kami Kumpulkan

Kami hanya mengumpulkan informasi yang benar-benar dibutuhkan untuk menyediakan fungsionalitas manajemen akademik dan pembukuan keuangan mahasiswa:

A. Data Otentikasi Akun & Layanan Pihak Ketiga (Google OAuth)

Saat Anda mendaftar atau masuk menggunakan fitur Google Sign-In (OAuth), kami meminta akses terbatas melalui otentikasi aman Supabase terhadap profil publik Google Anda:

  • Nama Lengkap: Digunakan untuk menampilkan identitas pengguna dan personalisasi kartu mahasiswa digital.
  • Alamat Email: Digunakan sebagai pengenal akun unik (ID), pengiriman kode konfirmasi/OTP, pemulihan kata sandi, dan sinkronisasi cloud.
  • Foto Profil (Avatar URL): Digunakan untuk menampilkan avatar pengguna pada kartu identitas mahasiswa digital di aplikasi.

B. Data Akademik & Studi (Diinput secara Sukarela)

  • Nama institusi/universitas, fakultas, program studi, dan semester aktif.
  • Jadwal mata kuliah mingguan (nama matkul, ruangan, dosen pengampu, jam perkuliahan).
  • Daftar tugas, tenggat waktu (*deadline*), dan status penyelesaian tugas.
  • Presensi kehadiran 16 pertemuan kuliah.
  • Nilai akademik dan kalkulasi Indeks Prestasi Kumulatif (IPK).

C. Data Finansial Pribadi

  • Catatan pemasukan, pengeluaran harian, dan tanggal transaksi.
  • Nama dompet atau rekening bank/e-wallet buatan sendiri (hanya nama alias seperti "Bank Jago", "GoPay", "Tunai", dan nilai saldo catatan). Kami TIDAK PERNAH meminta nomor kartu kredit, PIN, CVV, maupun password perbankan Anda.
  • Target tabungan, daftar tagihan bulanan, dan batas anggaran (*budget*) bulanan.

3. Kepatuhan Khusus terhadap Google API Services User Data Policy

Kepatuhan terhadap Kebijakan Data Pengguna Google (Limited Use Disclosure)

Penggunaan dan transfer informasi yang diterima MyKuliahLife dari API Google ke aplikasi lain akan mematuhi Google API Services User Data Policy , termasuk persyaratan Limited Use.

  • Kami TIDAK PERNAH mentransfer atau menjual data pengguna Google kepada broker data atau pihak ketiga manapun.
  • Kami TIDAK PERNAH menggunakan data pengguna Google untuk tujuan penayangan iklan (*advertising*), termasuk iklan bertarget atau retargeting.
  • Kami TIDAK PERNAH menggunakan data pengguna Google untuk melatih model kecerdasan buatan (AI/ML) umum tanpa persetujuan eksplisit.
  • Akses manusia (*human access*) terhadap data pengguna hanya dimungkinkan jika diizinkan oleh pengguna untuk penyelesaian kendala teknis atau atas dasar kewajiban hukum yang sah.

4. Bagaimana Kami Menggunakan Informasi Anda

Informasi yang kami kumpulkan digunakan secara eksklusif untuk tujuan:

  1. Otentikasi & Keamanan: Memverifikasi identitas pengguna saat login, mencegah akses tanpa izin, dan mengamankan akun.
  2. Sinkronisasi Multi-Device: Menyelaraskan catatan keuangan dan jadwal kuliah Anda di berbagai perangkat (smartphone, tablet, laptop) melalui cloud storage aman.
  3. Kalkulasi Otomatis: Menghitung sisa saldo, sisa hari siklus keuangan, batas belanja aman harian, rekomendasi IPK, dan ambang batas presensi 75%.
  4. Penerbitan Rekapitulasi (*e-Statement*): Menghasilkan rekapitulasi mutasi keuangan mandiri yang dapat diunduh pengguna dalam format CSV atau dokumen ringkasan.

5. Penyimpanan dan Keamanan Data

Kami menerapkan standar keamanan kelas industri untuk melindungi data Anda:

  • Enkripsi Data: Seluruh komunikasi antara browser Anda dan server kami dienkripsi menggunakan protokol HTTPS / TLS 1.3.
  • Penyimpanan Cloud Terenkripsi: Database kami di-host oleh Supabase (infrastruktur PostgreSQL berbasis enterprise) dengan enkripsi *data-at-rest* (AES-256).
  • Row Level Security (RLS): Akses database dikunci ketat menggunakan kebijakan RLS, sehingga pengguna hanya memiliki izin membaca dan mengubah data miliknya sendiri. Tidak ada pengguna lain yang dapat melihat catatan keuangan atau nilai kuliah Anda.

6. Mode Tamu (Guest Mode & Penyimpanan Lokal)

MyKuliahLife menyediakan opsi Mode Tamu (Guest Mode) di mana Anda dapat menggunakan fitur tanpa membuat akun. Dalam mode ini, seluruh data disimpan secara lokal pada peramban perangkat Anda (menggunakan localStorage) dan tidak dikirimkan ke server kami.

7. Hak Pengguna & Penghapusan Data (Data Deletion)

Sebagai pemilik data pribadi, Anda memiliki hak penuh untuk:

  • Mengakses & Memperbarui: Memeriksa dan mengedit data profil, keuangan, dan mata kuliah kapan saja melalui menu aplikasi.
  • Mengekspor Data: Mengunduh catatan mutasi transaksi dalam format CSV via fitur Laporan Keuangan.
  • Menghapus Akun & Data (Right to be Forgotten): Anda berhak menghapus seluruh data dan akun Anda secara permanen. Untuk menghapus data, Anda dapat menggunakan tombol pembersihan data di menu Profil atau mengirimkan permohonan ke email kami di bawah ini. Kami akan menghapus seluruh data yang terkait dengan akun Anda dalam kurun waktu maksimal 3x24 jam.

8. Batasan Usia

Layanan MyKuliahLife ditujukan untuk mahasiswa, pelajar tingkat lanjut, dan individu yang telah berusia minimal 17 tahun atau memiliki kapasitas hukum untuk menyetujui perjanjian penggunaan layanan.
